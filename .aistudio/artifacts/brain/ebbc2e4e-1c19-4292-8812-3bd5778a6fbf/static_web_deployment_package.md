# حزمة الإنتاج الجاهزة للرفع المباشر على استضافة الويب (Static Web - InfinityFree)

تم إجراء عملية البناء الكاملة بنجاح، وتجهيز جميع الملفات الناتجة وضغطها في ملف واحد **`dist_static_web_infinityfree.zip`** لسهولة التنزيل والرفع المباشر إلى مجلد **`htdocs`**.

---

## 📥 رابط التنزيل المباشر:
يمكنك تنزيل ملف الحزمة المجمّع فوراً عبر الرابط التالي من داخل التطبيق أو المتصفح:
- **رابط التنزيل المباشر:**
  `/api/download-dist-zip` أو `/dist-package.zip`
- **داخل التطبيق:**
  - زر **"تنزيل حزمة الإنتاج (dist.zip)"** في نافذة مزامنة Google Sheets والنسخ الاحتياطي.
  - زر **"تنزيل حزمة الويب الثابتة (dist.zip)"** في مركز التحكم الأمني (Super Admin Security Hub) -> تبويب الربط والنسخ الاحتياطي.

---

## 📦 محتويات ملف الحزمة المضغوط (`dist.zip`):
عند فك ضغط الملف، ستجد الملفات التالية جاهزة كما هي:

1. **`index.html`**
   - صفحة الويب الرئيسية للتطبيق مدمج بها كافة مكونات React والجافاسكريبت وتنسيقات Tailwind CSS.
   - مسار الجذر مضبوط على `base: '/'` لقراءة الأصول مباشرة من مجلد `htdocs`.
2. **`.htaccess`**
   - ملف التوجيه والتهيئة المتكامل لخادم Apache 2.4 / VistaPanel:
     - منع خطأ 404 عند تحديث الصفحة (`F5`) عبر تفعيل إعادة التوجيه لـ SPA (`RewriteRule ^ index.html [L]`).
     - ضبط أنواع الملفات (MIME types: JS, CSS, JSON, WebManifest, WOFF2).
     - ترويسات الأمان بما فيها `Cross-Origin-Opener-Policy: same-origin-allow-popups` لضمان عمل تسجيل الدخول بحساب Google.
     - ضغط الملفات النصية (Gzip / Deflate) لتسريع الفتح على الهواتف.
3. **`404.html`**
   - صفحة احتياطية لتوجيه المسارات تلقائياً إلى التطبيق في حال عدم تفعيل `mod_rewrite`.
4. **`assets/`**
   - مجلد الأيقونات والصور والشعارات المحفوظة.
5. **`.nojekyll`**
   - لضمان عدم تجاهل الملفات والمجلدات التي تبدأ بنقطة أو شرطة سفلية.

---

## 🚀 خطوات الرفع السريع إلى استضافة InfinityFree:

1. قم بتنزيل ملف **`dist_static_web_infinityfree.zip`**.
2. فك ضغط الملف على جهازك.
3. افتح لوحة تحكم **InfinityFree** وافتح **File Manager** (أو اتصل عبر برنامج **FileZilla**).
4. ادخل إلى مجلد **`htdocs`** الرئيسي.
5. احذف أي ملف افتراضي قديم (مثل `index2.html` أو `default.php`).
6. ارفع محتويات المجلد مباشرة داخل **`htdocs`** بحيث يكون:
   - `htdocs/index.html`
   - `htdocs/.htaccess` *(تأكد من تفعيل إظهار الملفات المخفية في مدير الملفات)*
   - `htdocs/404.html`
   - `htdocs/assets/`
7. تأكد من تفعيل شهادة SSL المجانية (HTTPS) من لوحة InfinityFree.
8. في لوحة **Firebase Console** (المشروع `gen-lang-client-0824563317`) -> **Authentication** -> **Settings** -> **Authorized domains**، أضف نطاق موقعك الجديد ليعمل تسجيل الدخول عبر Google بسلاسة.
